# 3D Printed Parts

This folder contains the STL files for the 3D printed frame and leg components of the Quadruped Spider Robot.

## Credits

The 3D models are sourced from **Robot LK** as part of their 3-in-1 Spider Robot (Quadruped) project.

- **Original project:** [3-in-1 Spider Robot (Quadruped) using Arduino](https://robotlk.com/3-in-1-spider-robot-quadruped-using-arduino/)
- **Downloads page:** [robotlk.com/downloads](https://robotlk.com/downloads/#3-in-1-spider-robot)
- **Author:** Robot LK (robotlk.com)

## Parts

The robot uses 22 3D printed parts in total, making up the body frame and the 4 legs (3 segments each).

## Print Settings

Recommended settings based on the original design:
- Material: PLA
- Infill: 20–30%
- Layer height: 0.2mm
- Supports: where needed for overhangs
